- This is currently a documentation/catalog foundation, not a functional server module.
- Distinguish tested interface behavior, imported client evidence, design choices and unimplemented server behavior.

- Imported spell IDs are references until collision checks and server/client behavior are validated.
- Run python tools/validate_records.py before committing catalog/documentation changes.
